title: GeoTrack — Field Routing & Live-Location Backend
summary: Address search, routing and navigation for field teams on an OpenStreetMap stack, plus a NestJS backend with a live-location channel. No Google Maps dependency.
---

## Problem

A field worker needs to find an address by typing it, get a route there and navigate. The office needs a channel that carries each worker's position live. The default answer, the Google Maps SDK, bills per request and ties the product to one vendor. I wanted to see how far OpenStreetMap goes.

## Role

I built it alone: the Flutter app, two iterations of the backend and a separate admin app.

## Architecture

The mobile app is MVVM on Riverpod. A `MapViewModel` owns one immutable `MapState` (position, search results, route, navigation mode) and a `MapService` calls Nominatim for address search and a self-hosted OSRM instance for driving routes. Tiles come from OpenStreetMap through flutter_map, and search input is debounced before it reaches Nominatim. The position stream runs only while navigation is on.

The backend began as a single-file Express API with JWT, roles and PostgreSQL. I rewrote it in NestJS with TypeORM and a Socket.IO gateway: the token is verified on the handshake, every user gets a room, and admins subscribe to the users they follow. A second Flutter app serves admin accounts only.

## Decisions

- OpenStreetMap, OSRM and Nominatim instead of the Google Maps SDK, because there is no per-request fee and I can host routing myself.
- A 10-metre distance filter on the Geolocator stream instead of a fixed timer, because a parked vehicle should cost neither battery nor traffic.
- Broadcasting every position but writing to PostgreSQL at most once a minute per user, instead of storing every fix, because the live view needs freshness and the history does not.
- NestJS instead of growing the Express file, because guards, validation and the WebSocket gateway needed module boundaries.

## Outcome

Search, routing and navigation mode work on a map stack with no licence fee. The admin app lists trackable users. The live channel is built and tested on the backend; wiring the two clients to it is next. What I learned: a free map stack moves the cost from invoices to operations. I run OSRM myself and follow Nominatim's usage policy.
